Core APIs @napacitor/core / 运行时

分组:运行时 · MAUI ⇄ Web 交互 GitHub 源码 ↗

桥层基础交互能力(对应 Capacitor 的 Core APIs):平台工具、插件可用性探测、JS console 转发(loggingBehavior)与原生主动事件(TriggerJSEventAsync)。

平台与环境


            
getPlatform() / isNativePlatform() / isPluginAvailable() / convertFileUri() —— 在浏览器中直接打开同样可用(web 实现)。Camera 未安装,用于演示 false 分支。

        

    


    

        
console 转发(loggingBehavior)

        

            

                
                
                
            

            
原生桥把 console 转发到原生日志(IDE 诊断输出 / 平台控制台,前缀 [Napacitor][JS]);loggingBehavior = debug 时仅 Debug 构建转发,Web 本地输出始终保留。

        

    


    

        
原生主动事件(TriggerJSEventAsync)

        

            

                
            

            

            
点击宿主窗口顶部的原生按钮(MainPage.xaml):「派发原生事件」触发 TriggerJSEventAsync,「读取 Web 资产」经 JS 同源通道读取 wwwroot 文件后回传 —— 验证 C# → Web 的主动交互通道(对应 Capacitor 的 triggerJSEvent)。

        

    


    

        
代码示例

        
import { Napacitor } from '@napacitor/core';

Napacitor.getPlatform();                // 'windows' / 'android' / 'ios' / 'web'
Napacitor.isNativePlatform();           // 原生宿主中为 true
Napacitor.isPluginAvailable('Battery');

// 原生(C#)主动派发的事件,Web 侧普通 DOM 监听即可:
//   await runtime.TriggerJSEventAsync("napacitor:tick", new { time = … });
window.addEventListener('napacitor:tick', (e) => {
  console.log('收到原生事件', e.detail);
});
