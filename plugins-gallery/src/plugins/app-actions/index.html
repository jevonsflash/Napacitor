App Actions @napacitor/app-actions

分组:系统功能 · 注册名:AppActions GitHub 源码 ↗

应用图标快捷方式(Android App Shortcuts / iOS 主屏 Quick Actions / Windows 任务栏跳转列表——仅 MSIX 打包应用)。对应 .NET MAUI AppActions API。

调试

结果将显示在这里(设置后长按 / 右键应用图标可见快捷方式)

appActionPerformed 事件需宿主在 MauiProgram 的 ConfigureEssentials 中转发(essentials.OnAppAction(action => AppActionsPlugin.NotifyActionPerformed(action))),Android 还需 MainActivity 的 IntentFilter,详见插件 README;Windows 未打包(WindowsPackageType=None)应用不支持。

代码示例

import { AppActions } from '@napacitor/app-actions';

// 检查平台支持后设置快捷方式(整体替换)
const { supported } = await AppActions.isSupported();
if (supported) {
  await AppActions.set({
    actions: [
      { id: 'inbox', title: '收件箱', subtitle: '查看新邮件' },
      { id: 'compose', title: '写邮件' },
    ],
  });
}

// 读取当前快捷方式
const { actions } = await AppActions.get();

// 响应快捷方式点击(需宿主转发,见 README)
await AppActions.addListener('appActionPerformed', ({ action }) => {
  console.log('触发了快捷方式:', action.id);
});
