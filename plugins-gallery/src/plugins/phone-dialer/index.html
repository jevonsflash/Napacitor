Phone Dialer @napacitor/phone-dialer

分组:通讯 · 注册名:PhoneDialer GitHub 源码 ↗

打开系统拨号界面并预填号码(不会直接拨出)。对应 .NET MAUI PhoneDialer API。

调试

仅打开拨号界面并预填号码,不会自动拨出;桌面设备通常不支持。

代码示例

import { PhoneDialer } from '@napacitor/phone-dialer';

const { supported } = await PhoneDialer.isSupported();
if (supported) {
  await PhoneDialer.open({ number: '10086' });
}
