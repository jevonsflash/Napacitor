Preferences @napacitor/preferences

分组:数据交互 · 注册名:Preferences GitHub 源码 ↗

键值对持久化存储(仅字符串,复杂对象请自行 JSON.stringify)。对应 .NET MAUI Preferences API(iOS:UserDefaults / Android:SharedPreferences / Windows:ApplicationData)。

调试

MAUI 原生不支持枚举键,故不提供 keys();切换存储组后,后续读写/清空均作用于该组。

代码示例

import { Preferences } from '@napacitor/preferences';

// 切换到指定存储组(可选)
await Preferences.configure({ group: 'settings' });

// 写入 / 读取 / 删除
await Preferences.set({ key: 'theme', value: 'dark' });
const { value } = await Preferences.get({ key: 'theme' });
await Preferences.remove({ key: 'theme' });

// 清空当前组
await Preferences.clear();
