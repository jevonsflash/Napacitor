Browser @napacitor/browser

分组:系统功能 · 注册名:Browser GitHub 源码 ↗

系统内嵌浏览器(Android Custom Tabs / iOS SFSafariViewController / 桌面回退到外部浏览器)。对应 .NET MAUI Browser API。

调试

MAUI Browser API 未提供跨平台关闭入口,close() 原生端抛出 NOT_IMPLEMENTED;browerFinished / browserPageLoaded 事件同样需要平台代码,当前不派发。

代码示例

import { Browser } from '@napacitor/browser';

// 打开内嵌浏览器(工具栏颜色平台不支持时忽略)
await Browser.open({
  url: 'https://github.com/jevonsflash/napacitor',
  toolbarColor: '#512BD4',
});

// 关闭:MAUI 无跨平台关闭入口,当前抛出 NOT_IMPLEMENTED
// (Android Custom Tabs / iOS SFSafariViewController 需少量平台代码)
await Browser.close();
