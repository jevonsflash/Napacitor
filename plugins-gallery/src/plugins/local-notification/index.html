Local Notification @napacitor/local-notification

分组:交互反馈 · 注册名:LocalNotification GitHub 源码 ↗

立即或定时发送系统本地通知,支持权限请求、取消与点击回调(Android / iOS / Mac Catalyst / Windows 全平台)。

调试

取消使用最近一次发送返回的 id;点击通知后应用被唤起(或在前台)时弹窗提示。Android 热启动点击暂不支持(见插件 README 局限)。

代码示例

import { LocalNotification } from '@napacitor/local-notification';

// 请求权限(Android 13+ / iOS / Mac Catalyst 弹系统对话框)
const { granted } = await LocalNotification.requestPermission();

// 立即发送
const { notifications } = await LocalNotification.schedule({
  notifications: [{ title: '提醒', body: '该喝水了', id: 1 }],
});

// 定时发送(ISO 8601 时间)
await LocalNotification.schedule({
  notifications: [{ title: '会议', body: '15:00 开会', id: 2, at: '2026-11-03T15:00:00Z' }],
});

// 取消
await LocalNotification.cancel({ notifications: [{ id: 1 }] });

// 点击回调
const handle = await LocalNotification.addListener('notificationReceived', (payload) => {
  console.log(payload.id, payload.title, payload.body);
});
