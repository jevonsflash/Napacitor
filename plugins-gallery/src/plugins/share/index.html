Share @napacitor/share

分组:数据交互 · 注册名:Share GitHub 源码 ↗

调起系统分享面板,分享文本与链接到其他应用。可先通过 canShare() 检测当前平台是否支持。

调试

代码示例

import { Share } from '@napacitor/share';

// 先检测是否支持分享
const { canShare } = await Share.canShare();
if (!canShare) return;

// 弹出系统分享面板
await Share.share({
  title: 'Napacitor Demo',
  text: '用 Web 技术构建的原生应用',
  url: 'https://github.com/jevonsflash/napacitor',
  dialogTitle: '分享到…',
});
