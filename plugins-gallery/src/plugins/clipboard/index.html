Clipboard @napacitor/clipboard

分组:数据交互 · 注册名:Clipboard GitHub 源码 ↗

读写系统剪贴板文本。对应 .NET MAUI Clipboard API(图像复制暂未实现,将返回 NOT_IMPLEMENTED)。

调试

代码示例

import { Clipboard } from '@napacitor/clipboard';

// 写入文本
await Clipboard.write({ string: 'hello napacitor' });

// 读取文本(空剪贴板返回空字符串)
const { value } = await Clipboard.read();
console.log(value);
