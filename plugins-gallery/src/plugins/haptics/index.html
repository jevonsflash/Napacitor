Haptics @napacitor/haptics

分组:交互反馈 · 注册名:Haptics GitHub 源码 ↗

触发设备触觉反馈:自定义时长振动、冲击/通知触觉、选择变化轻触。桌面与模拟器上部分平台为无操作。对应 .NET MAUI Vibration API。

调试

桌面平台(Windows / macOS)与模拟器通常无振动马达,调用为无操作且不会报错。

代码示例

import { Haptics, ImpactStyle, NotificationType } from '@napacitor/haptics';

// 自定义时长振动(毫秒)
await Haptics.vibrate({ duration: 40 });

// 冲击 / 通知触觉
await Haptics.impact({ style: ImpactStyle.Medium });
await Haptics.notification({ type: NotificationType.Success });

// 列表选择时的轻微触觉
await Haptics.selection();
