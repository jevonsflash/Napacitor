App Launcher @napacitor/app-launcher

分组:系统功能 · 注册名:AppLauncher GitHub 源码 ↗

打开 URL、唤起其他应用(按包名 / Bundle ID)、跳转系统地图定位。对应 .NET MAUI Launcher / Map API。

调试

代码示例

import { AppLauncher } from '@napacitor/app-launcher';

// 打开 URL(浏览器或系统处理)
await AppLauncher.openUrl({ url: 'https://github.com' });

// 检查能否处理 / 应用是否已安装
const a = await AppLauncher.canOpenUrl({ url: 'mailto:' });
const b = await AppLauncher.canOpenApp({ appId: 'com.android.chrome' });

// 打开系统地图并定位
await AppLauncher.openMap({ latitude: 39.9042, longitude: 116.4074, label: '北京' });
