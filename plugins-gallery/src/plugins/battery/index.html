Battery @napacitor/battery

分组:设备信息 · 注册名:Battery GitHub 源码 ↗

获取电池电量与充电状态,并可通过 batteryStatusChange 事件实时监听电量变化(原生端主动推送,无需轮询)。

调试

监听开启后,电量或充电状态变化会弹窗提醒。

代码示例

import { Battery } from '@napacitor/battery';

// 一次性读取
const { batteryLevel, isCharging } = await Battery.getBatteryInfo();
console.log(Math.round(batteryLevel * 100) + '%', isCharging);

// 持续监听电量与充电状态变化
const handle = await Battery.addListener('batteryStatusChange', (info) => {
  console.log(info.batteryLevel, info.isCharging);
});
// handle.remove() 停止监听
