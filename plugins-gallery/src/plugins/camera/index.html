Camera @napacitor/camera

分组:硬件控制 · 注册名:Camera GitHub 源码 ↗

拍照 / 录像与媒体库选取照片、视频。对应 .NET MAUI MediaPicker API(Windows 桌面无内置相机 UI,拍照/录像依赖系统相机应用)。

调试

结果将显示在这里

照片类结果会在下方预览;base64 内容展示时截断;path 仅平台可用时返回,不可依赖。selectionLimit 在 Android 部分选择器 UI 不强制、Windows 不支持。

代码示例

import { Camera } from '@napacitor/camera';

// 设备是否支持拍照 / 录像
const supported = await Camera.isCaptureSupported();

// 从媒体库选取照片(可带图像处理参数)
const photos = await Camera.pickPhotos({
  selectionLimit: 3,
  maximumWidth: 1280,
  compressionQuality: 80,
});

// 拍一张照片(取消返回 null)
const photo = await Camera.capturePhoto();
if (photo) {
  // photo.data 为 base64,photo.contentType 如 'image/jpeg'
  const src = `data:${photo.contentType || 'image/jpeg'};base64,${photo.data}`;
}

// 录像(取消返回 null)
const video = await Camera.captureVideo();
