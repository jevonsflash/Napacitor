Email @napacitor/email

分组:通讯 · 注册名:Email GitHub 源码 ↗

唤起系统邮件客户端编写邮件:支持收件人、抄送、主题、正文(纯文本或 HTML)。对应 .NET MAUI Email API。

调试

代码示例

import { Email } from '@napacitor/email';

const { supported } = await Email.isSupported();
if (supported) {
  await Email.compose({
    to: ['someone@example.com'],
    subject: '来自 Napacitor',
    body: '<b>用 Web 技术构建的原生应用</b>',
    isHtml: true,
  });
}
