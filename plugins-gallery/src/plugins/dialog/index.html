Dialog @napacitor/dialog

分组:交互反馈 · 注册名:Dialog GitHub 源码 ↗

原生对话框:alert / prompt / confirm。映射 MAUI Page.DisplayAlert / DisplayPromptAsync(Windows 上由 MAUI 落到 ContentDialog)。

调试

confirm / prompt 的返回结果将显示在这里

代码示例

import { Dialog } from '@napacitor/dialog';

// 警告框
await Dialog.alert({
  title: '提示',
  message: '这是一个原生对话框',
  buttonTitle: '知道了',
});

// 确认框(返回 { value: boolean })
const { value } = await Dialog.confirm({
  title: '删除',
  message: '确定要删除吗?',
});

// 输入框(返回 { value, cancelled })
const result = await Dialog.prompt({
  title: '重命名',
  message: '请输入新名称',
  inputPlaceholder: '名称',
});
