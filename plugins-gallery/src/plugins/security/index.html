Security @napacitor/security

分组:数据交互 · 注册名:Security GitHub 源码 ↗

安全键值存储(封装 MAUI SecureStorage):iOS Keychain / Android EncryptedSharedPreferences + Keystore / Windows DataProtectionProvider,适合存放令牌等敏感数据。

调试

键值仅支持字符串,复杂对象请自行 JSON.stringify;与 Preferences 的区别在于数据经系统安全机制加密存储。

代码示例

import { Security } from '@napacitor/security';

// 写入(仅字符串,复杂对象请自行 JSON.stringify)
await Security.set({ key: 'api_token', value: 'secret-value' });

// 读取(未设置过时 value 为 null)
const { value } = await Security.get({ key: 'api_token' });

// 删除单个键 / 清空全部
await Security.remove({ key: 'api_token' });
await Security.clear();
