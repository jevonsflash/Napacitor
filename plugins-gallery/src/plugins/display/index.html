Display @napacitor/display

分组:设备信息 · 注册名:Display GitHub 源码 ↗

屏幕信息与显示控制(封装 MAUI DeviceDisplay):读取分辨率/密度/方向/刷新率,保持屏幕常亮,运行时锁定屏幕方向,并可监听屏幕指标变化。

调试

锁方向在 Android/iOS/Mac Catalyst 有效,Windows 不支持(会抛 NOT_IMPLEMENTED)。

代码示例

import { Display } from '@napacitor/display';

// 一次性读取
const info = await Display.getInfo();
console.log(info.width, info.height, info.density, info.orientation, info.refreshRate);

// 保持屏幕常亮
await Display.setKeepAwake({ keepAwake: true });

// 锁定 / 解锁方向(Android/iOS/Mac Catalyst)
await Display.lock({ orientation: 'portrait' });
await Display.unlock();

// 持续监听屏幕指标变化
const handle = await Display.addListener('displayChange', (info) => {
  console.log(info.orientation, info.width + 'x' + info.height);
});
// handle.remove() 停止监听
