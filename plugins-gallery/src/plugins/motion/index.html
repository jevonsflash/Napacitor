Motion @napacitor/motion

分组:传感器 · 注册名:Motion GitHub 源码 ↗

统一封装五类运动传感器:加速度计、陀螺仪、磁力计、指南针、气压计。按需启停、选择采样速率,读数经事件持续推送。对应 .NET MAUI Sensors 系列 API。

调试

启动监听后,最新读数将显示在这里

桌面设备通常仅有部分传感器可用,请在真机体验完整效果;切换传感器再点启动会自动停止上一个监听。

代码示例

import { Motion, SensorSpeed } from '@napacitor/motion';

// 检测支持后启动加速度计
const { supported } = await Motion.isAccelerometerSupported();
if (supported) {
  await Motion.startAccelerometer({ speed: SensorSpeed.Game });
  await Motion.addListener('accelerometerReading', (r) => {
    console.log(r.x, r.y, r.z);
  });
}

// 用完记得停止以省电
await Motion.stopAccelerometer();
