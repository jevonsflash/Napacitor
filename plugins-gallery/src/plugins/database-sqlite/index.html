Database Sqlite @napacitor/database-sqlite

分组:数据交互 · 注册名:DatabaseSqlite GitHub 源码 ↗

本地 SQLite 数据库(基于 Microsoft.Data.Sqlite):建表、参数化增删改查、事务与数据库文件管理。占位符用 ? 或 $1、$2。

调试

execute() 可一次执行多条分号分隔的语句;query() 用于 SELECT,结果逐行弹窗展示。

代码示例

import { DatabaseSqlite } from '@napacitor/database-sqlite';

// 建表(可多条语句顺序执行,transaction 为 true 时整体回滚)
await DatabaseSqlite.execute({
  statements: 'CREATE TABLE IF NOT EXISTS users (id INTEGER PRIMARY KEY AUTOINCREMENT, name TEXT NOT NULL);',
});

// 参数化写入(占位符 ? 或 $1、$2)
const { changes, lastId } = await DatabaseSqlite.run({
  statement: 'INSERT INTO users (name) VALUES (?)',
  values: ['张三'],
});

// 参数化查询
const { values } = await DatabaseSqlite.query({
  statement: 'SELECT * FROM users WHERE name = ?',
  values: ['张三'],
});

// 数据库文件管理
await DatabaseSqlite.getDatabaseList();
await DatabaseSqlite.deleteDatabase({ database: 'todo.db3' });
