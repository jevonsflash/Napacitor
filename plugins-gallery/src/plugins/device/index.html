Device @napacitor/device

分组:设备信息 · 注册名:Device GitHub 源码 ↗

获取设备基础信息:型号、平台、操作系统版本、制造商、是否虚拟设备,以及当前 UI 语言代码与区域设置。对应 .NET MAUI DeviceInfo API。

调试

代码示例

import { Device } from '@napacitor/device';

// 设备基础信息
const info = await Device.getInfo();
console.log(info.platform, info.model, info.osVersion);

// 语言与区域(如 zh、zh-CN)
const { value: lang } = await Device.getLanguageCode();
const { value: locale } = await Device.getLocale();
