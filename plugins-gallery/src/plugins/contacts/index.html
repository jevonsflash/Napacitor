Contacts @napacitor/contacts

分组:通讯 · 注册名:Contacts GitHub 源码 ↗

读取设备全部联系人与系统联系人选择器。对应 .NET MAUI Contacts API(仅只读,不含写入/修改)。

调试

结果将显示在这里

getContacts 需要联系人读取权限,拒绝时抛错;pickContact 在 Windows 上不受支持(抛 UNSUPPORTED),取消时返回 null。

代码示例

import { Contacts } from '@napacitor/contacts';

// 读取设备上的全部联系人(权限拒绝时抛错)
const contacts = await Contacts.getContacts();
for (const c of contacts) {
  console.log(c.displayName, c.phones.map((p) => p.phoneNumber));
}

// 打开系统联系人选择器(取消返回 null;Windows 不支持)
const picked = await Contacts.pickContact();
if (picked) {
  console.log(picked.displayName, picked.emails);
}
