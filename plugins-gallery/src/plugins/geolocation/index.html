Geolocation @napacitor/geolocation

分组:传感器 · 注册名:Geolocation GitHub 源码 ↗

GPS 定位:一次性获取、持续监听与权限管理。对应 .NET MAUI Geolocation / Permissions API(桌面平台通常无 GPS,定位来源为 IP/Wi-Fi,精度较低)。

调试

定位结果将显示在这里

监听使用 position / error 两个事件推送;MAUI 的持续定位为单会话,同一时刻只能有一个 watch。

代码示例

import { Geolocation } from '@napacitor/geolocation';

// 一次性获取当前位置
const position = await Geolocation.getCurrentPosition({
  enableHighAccuracy: true,
  timeout: 10000,
});
console.log(position.coords.latitude, position.coords.longitude);

// 持续监听(回调式,返回 ID 供 clearWatch 使用)
const id = await Geolocation.watchPosition(
  { enableHighAccuracy: true },
  (position, err) => {
    if (err) return console.error(err.code, err.message);
    console.log(position.coords);
  },
);
await Geolocation.clearWatch({ id });
