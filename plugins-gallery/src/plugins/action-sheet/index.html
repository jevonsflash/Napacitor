Action Sheet @napacitor/action-sheet

分组:交互反馈 · 注册名:ActionSheet GitHub 源码 ↗

原生操作表(底部弹出的选项菜单)。映射 MAUI Page.DisplayActionSheet;style 仅 iOS 生效,其余平台忽略。

调试

选择结果将显示在这里

代码示例

import { ActionSheet, ActionSheetButtonStyle } from '@napacitor/action-sheet';

const { index, canceled } = await ActionSheet.showActions({
  title: '选择一个操作',
  options: [
    { title: '拍照' },
    { title: '从相册选择' },
    { title: '删除', style: ActionSheetButtonStyle.Destructive }, // 仅 iOS 生效
  ],
  cancelable: true, // 显示取消按钮
});

if (!canceled) {
  console.log('选择了第', index, '项');
}
