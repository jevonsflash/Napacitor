File Viewer @napacitor/file-viewer

分组:系统功能 · 注册名:FileViewer GitHub 源码 ↗

用系统查看器打开文件。映射 MAUI Launcher.OpenAsync(Android:Intent.ACTION_VIEW / Windows:Shell 默认打开方式)。

调试

包内资源会先复制到缓存目录再交给查看器(打包资源无法直接以路径形式提供给外部应用);远程地址交由系统浏览器/下载器接管,不会自动下载后弹出查看器。

代码示例

import { FileViewer } from '@napacitor/file-viewer';

// 本地绝对路径
await FileViewer.openDocumentFromLocalPath({
  path: '/storage/emulated/0/Download/sample.pdf',
});

// 应用包内资源(Resources/Raw 下的相对路径)
await FileViewer.openDocumentFromResources({
  path: 'docs/sample.pdf',
});

// 远程文件(交由系统浏览器/下载器处理)
await FileViewer.openDocumentFromUrl({
  url: 'https://example.com/sample.pdf',
});
