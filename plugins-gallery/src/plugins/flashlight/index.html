Flashlight @napacitor/flashlight

分组:硬件控制 · 注册名:Flashlight GitHub 源码 ↗

控制设备手电筒:开、关、切换、查询当前状态,部分平台支持亮度调节(0.1 - 1.0)。对应 .NET MAUI Flashlight API。

调试

亮度仅部分平台支持;无手电筒硬件的设备调用会返回不支持错误。

代码示例

import { Flashlight } from '@napacitor/flashlight';

const { supported } = await Flashlight.isSupported();
if (supported) {
  await Flashlight.switchOn({ intensity: 1.0 });
  const { isOn } = await Flashlight.getState();
  console.log(isOn);
  await Flashlight.switchOff();
}
