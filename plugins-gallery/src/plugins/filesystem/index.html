Filesystem @napacitor/filesystem

分组:系统功能 · 注册名:Filesystem GitHub 源码 ↗

文件系统路径与捆绑文件访问 + 系统文件选择器。对应 .NET MAUI FileSystem / FilePicker API。

调试

结果将显示在这里

选取到的文件内容以 base64 返回(展示时截断);path 仅平台可用时返回,不可依赖。选择器标题在 Windows 上不会显示。

代码示例

import { Filesystem } from '@napacitor/filesystem';

// 获取缓存目录与应用数据目录
const paths = await Filesystem.getDirectoryPaths();
console.log(paths.cacheDirectory, paths.dataDirectory);

// 读取应用包内捆绑文件(Resources/Raw 下)
const { data } = await Filesystem.readBundleFile({
  path: 'config/settings.json',
});

// 将捆绑文件复制到缓存目录并拿到绝对路径
const { path } = await Filesystem.copyBundleFile({
  path: 'config/settings.json',
  targetDirectory: 'data',
});

// 系统文件选择器(取消时单个返回 null、多个返回空数组)
const file = await Filesystem.pickFile({ types: 'images' });
const files = await Filesystem.pickFiles();
