Sms @napacitor/sms

分组:通讯 · 注册名:Sms GitHub 源码 ↗

唤起系统短信客户端编写短信:指定收件人列表与可选正文。对应 .NET MAUI Sms API。

调试

发送不会直接发出,只会打开系统短信客户端并预填内容,由用户确认发送。

代码示例

import { Sms } from '@napacitor/sms';

const { supported } = await Sms.isSupported();
if (supported) {
  await Sms.send({
    recipients: ['10086'],
    body: '查询余额',
  });
}
