App Info @napacitor/app-info

分组:设备信息 · 注册名:AppInfo GitHub 源码 ↗

获取当前应用信息:名称、包名、版本号、构建号、主题模式,以及版本跟踪(是否首次安装、历史版本列表)。对应 .NET MAUI AppInfo / VersionTracking API。

调试

代码示例

import { AppInfo } from '@napacitor/app-info';

// 应用基础信息
const info = await AppInfo.getInfo();
console.log(info.name, info.version, info.build);

// 版本跟踪:首次启动判断与历史版本
const tracking = await AppInfo.getVersionTracking();
console.log(tracking.isFirstLaunchEver, tracking.versionHistory);

// 跳转系统设置页
await AppInfo.openSettings();
