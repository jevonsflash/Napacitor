Connectivity @napacitor/connectivity

分组:设备信息 · 注册名:Connectivity GitHub 源码 ↗

检测网络连接状态:连接类型(WiFi / 蜂窝 / 以太网…)、网络访问级别,并可通过 connectivityChange 事件监听网络变化。对应 .NET MAUI Connectivity API。

调试

代码示例

import { Connectivity } from '@napacitor/connectivity';

// 当前网络状态
const status = await Connectivity.getStatus();
console.log(status.connectionType, status.networkAccess, status.isConnected);

// 监听网络变化(断网 / 恢复)
const handle = await Connectivity.addListener('connectivityChange', (s) => {
  console.log(s.isConnected ? '网络已恢复' : '网络已断开');
});
