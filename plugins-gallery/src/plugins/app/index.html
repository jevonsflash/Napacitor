App @napacitor/app

分组:运行时 · 注册名:App GitHub 源码 ↗

应用生命周期(appStateChange / pause / resume)、返回键、深链、退出与语言。映射 MAUI Window 生命周期事件 + Application.Quit + CultureInfo。

调试

生命周期事件日志将显示在这里(把应用切到后台再切回试试)

appUrlOpen / backButton 事件需宿主模板转发(深度链接注册 URL scheme、Android 返回键重写 OnBackPressed),详见插件 README;exitApp 在 Windows/macOS 有效,Android/iOS 系统不鼓励程序化退出。

代码示例

import { App } from '@napacitor/app';

// 应用前后台切换
await App.addListener('appStateChange', ({ isActive }) => {
  console.log(isActive ? '回到前台' : '进入后台');
});
await App.addListener('pause', () => console.log('pause'));
await App.addListener('resume', () => console.log('resume'));

// 应用状态 / 语言 / 启动深链
const state = await App.getState();
const { value } = await App.getAppLanguage();
const { url } = await App.getLaunchUrl();

// 退出应用(Windows/macOS)
await App.exitApp();
